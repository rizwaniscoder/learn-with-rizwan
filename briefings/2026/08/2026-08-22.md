## 🛠️ New tools gaining traction

- **ai-memory (Fabio Akita)** — Rust MCP server for long-term memory + cross-agent handoff across Claude Code, Codex, OpenCode, Cursor, Gemini CLI, OMP-Pi.
  *Traction:* Hit **#1 on GitHub Trending Aug 18**; **~2,404 stars this week** (~3,970 total). Author is a well-known dev-community voice.
  *Why it matters:* First widely-adopted answer to "my agent forgot everything when I switched vendors" — MCP-native memory + continuity in one package instead of proprietary per-vendor silos. [Repo](https://github.com/akitaonrails/ai-memory)

- **OpenViking (ByteDance/Volcengine)** — open-source context DB that exposes agent memory, RAG, and skills as one virtual filesystem under `viking://`, traversed with `ls`/`tree`/`find` instead of vector queries.
  *Traction:* **~3,033 stars this week** (~31.7K total), still on GitHub weekly trending Aug 22; vendor benchmarks: 43% higher task completion, 91% lower input token cost vs native OpenClaw. [Repo](https://github.com/volcengine/OpenViking)
  *Why it matters:* Auditable, hierarchical (L0/L1/L2) alternative to vector-store memory from a major cloud vendor — a plausible standard now that MCP itself went stateless on July 28.

- **Cactus Needle 2** — 45M-parameter tool-calling model that ships as a **14MB binary** in ~28MB RAM.
  *Traction:* **~2,985 stars this week** (~8.4K total) on GitHub weekly trending; Show HN on the HN front page; Cactus Compute has $9.5M backing (Wellington, Pelion, Batch Ventures). [Repo](https://github.com/cactus-compute/needle) · [MarkTechPost](https://www.marktechpost.com/2026/08/13/cactus-compute-needle-2-45m-parameter-tool-calling-model/)
  *Why it matters:* First credibly agentic (tool-calling, structured extraction) model small enough for sub-$200 phones, Vision Pro, Quest 3S, Raspberry Pi 5 — opens edge/wearable agent workloads that used to require a cloud round-trip.

- **"Reconstruction" benchmark (arXiv, Aug 17–19) — frontier models bottom out at 3–15% on genuinely novel hypothesis generation.** Stanford + Titan + Prentis blind test: recover the true hypothesis of a paper given only its (anonymized) reference list, across 643 papers in 6 domains. Solo models: 3–15%. A Swiss-tournament multi-agent ensemble reaches ~42%. Cleanest contamination-proof evidence to date that current LLMs synthesize existing literature far better than they generate novel ideas. [arXiv 2608.16645](https://arxiv.org/abs/2608.16645) · [TechTimes coverage](https://www.techtimes.com/articles/324932/20260819/blind-benchmark-catches-frontier-ai-just-three-percent-research-idea-recovery.htm)
