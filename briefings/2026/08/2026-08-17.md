  *Why now:* IBM's F500 sales motion will out-run its bench for at least two quarters; regional and vertical delivery gets subcontracted or pushed to the OpenAI partner registry.
  *Angle:* Package one vertical playbook (e.g. "Codex rollout for a regional bank — 90 days, fixed price"), certify 5-10 engineers on OpenAI's platform this month, apply as a Solutions/Delivery partner and pitch it directly to IBM Consulting practice leads in your region. ## 🛠️ New tools gaining traction

- **OpenAI Ultrafast (preview, Aug 13)** — GPT-5.6 Sol on Cerebras hardware at up to ~750 output tokens/sec, roughly 14× the standard tier at unchanged intelligence.
  *Traction:* Waitlist-only, no GA date, no price — but every latency-sensitive OpenAI shop (voice, trading, security triage) is on it. Cerebras confirmed the deployment publicly.
  *Why it matters:* First frontier lab to productize a specialty-silicon inference tier — expect Anthropic/Google to follow within a quarter. [OpenAI](https://openai.com/index/previewing-ultrafast/) · [Cerebras](https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai)

- **Bifrost (LLM + MCP gateway)** — Go-based open-source AI gateway that acts as both an MCP client and server; published overhead 11µs at 5,000 rps.
  *Traction:* Called out in the 2026 enterprise MCP gateway shortlist alongside Docker MCP Gateway, Microsoft MCP Gateway and IBM ContextForge.
  *Why it matters:* First serious contender to a commercial LLM router (OpenRouter, Portkey) that ships MCP inside the same binary. [Lunar.dev roundup](https://www.lunar.dev/post/the-best-open-source-mcp-gateways-in-2026)

- **MaxKB** — open-source enterprise agent platform, 22.5k+ GitHub stars, active development through Aug 10.
  *Traction:* Consistently in OSSInsight's top-25 for AI agents; growing pull inside SEA and Chinese enterprise deployments as a Coze/Dify alternative.
  *Why it matters:* Free entry point for shops pitching "internal knowledge agent" pilots without lock-in to a hosted vendor. [Prefect](https://www.prefect.io/resources/best-mcp-deployment-platforms-enterprise-2026)

- **OpenClaw** — the runaway 2026 breakout is still climbing: ~374K GitHub stars, up from 210K in early July.
  *Traction:* Roughly 2K stars/day pace held through early August; the reference example every AI-open-source thinkpiece cites.
  *Why it matters:* Downstream distributions (forks, packaged installs) are where the services money lives; enterprises are asking for OpenClaw hardening the same way they asked for Kubernetes hardening in 2019. [Firecrawl repos](https://www.firecrawl.dev/blog/best-github-repos)
