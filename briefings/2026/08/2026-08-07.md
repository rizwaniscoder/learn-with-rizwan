## 🎯 Opportunity signals
*For founders and service businesses.*

- **Anthropic ships Inference Hooks (DLP webhook) inside Claude Enterprise beta (Aug 5) — regulated buyers now have a security ask nobody on your side has ever built**
  *What happened:* Every prompt and tool-call response routes through the customer's own DLP server (Netskope, Palo Alto, Proofpoint, Zscaler, or in-house) for an allow/deny verdict before Claude sees it. 5s timeout, shadow mode, role exclusions, percentage rollouts, published webhook schema. Covers Claude chat, Claude Code, and Claude Cowork.
  *Who can act on it:* AI services shops with security/compliance chops and existing Zscaler / Netskope / Palo Alto integration muscle; ex-SOC engineers who can write custom policy servers.
  *Why now:* Every EU financial-services and healthcare buyer just got a new box to tick on Claude Enterprise procurement, and the reference implementation doesn't exist yet.
  *Angle:* Fixed-fee "Claude Enterprise DLP Onboarding" — wire the webhook into their existing DLP, build custom policy handlers, run shadow-mode evals against 30 days of prompt traffic, phased rollout. $40–80K per deployment; publish an open-source reference server on GitHub as demand-gen. ## 🛠️ New tools gaining traction

- **Meta Muse Code (beta)** — terminal coding agent on Muse Spark 1.2 with parallel sub-agents, worktree isolation, and crash-safe resumable sessions.
  *Traction:* Same-day CNBC, TechCrunch, Engadget, VentureBeat, Forbes, Dataconomy, MarkTechPost, The Register coverage; $1.25/$4.25 pricing widely quoted as the below-Sonnet floor. Meta is not open-weight yet — Zuckerberg said "more to share soon."
  *Why it matters:* Muse Code is the first coding-agent priced explicitly to steal seats from Claude Code and Codex, and the first product from Meta's Superintelligence Labs. [Meta Dev Blog](https://developer.meta.com/ai/resources/blog/build-with-muse-code/)

- **Liquid AI LFM2.5-2.6B** — 2.6B-parameter on-device agentic model (base + post-trained) with day-one llama.cpp / MLX / vLLM / SGLang / ONNX support across Apple, AMD, Qualcomm silicon.
  *Traction:* 220 tok/s on Apple M5 Max, 113 tok/s on AMD Ryzen AI Max+ 395, ~30 tok/s on phones, fits in 2.5GB. Liquid claims parity with 4x-larger models on tool-use and instruction-following. Cross-runtime day-one availability is unusual for a sub-3B launch.
  *Why it matters:* Puts a legitimate agentic model on Raspberry-Pi-class hardware — opens on-device agents for regulated deployments (banking branches, hospital equipment, offline GCC sovereign use). [VentureBeat](https://venturebeat.com/technology/no-cloud-no-gpus-no-problem-liquid-ais-new-model-lfm2-5-2-6b-brings-powerful-ai-agents-to-devices-as-small-as-a-raspberry-pi) · [Liquid AI](https://www.liquid.ai/blog/introducing-lfm2-5-the-next-generation-of-on-device-ai)

- **Sapiom Router (public launch)** — agent-cost-routing platform that picks between models/tools per-call based on cost, quality, latency, and policy.
  *Traction:* 100K+ agent runs/day and 270M+ transactions processed in the 6 months since launch. $35M Series A closed Aug 5 (Dragonfly lead, Anthropic on the cap table). Three products: Router, Agent Studio, Runtime.
  *Why it matters:* Third public "agent gateway" to raise real institutional money after OpenRouter and LiteLLM — the control plane between models is now a fundable category. [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/sapiom-raises-35-million-series-170000223.html)
