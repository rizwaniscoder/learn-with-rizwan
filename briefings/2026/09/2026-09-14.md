## 🛠️ New tools gaining traction

- **PRAXIST (Sapient Intelligence)** — Open-source autonomous research agent running parallel "Research Peers" and storing evidence in a shared graph so later runs reuse validated mechanisms.
  *Traction:* 6.7k GitHub stars since Aug 27 launch; scored 49 gold medals on MLE-Bench's 75 Kaggle tasks vs 34 for Claude Code at ~10× lower cost, per the launch post.
  *Why it matters:* First open-source autonomous R&D loop to beat Claude Code head-to-head on MLE-Bench — the "AutoML agent" category just got a credible OSS entrant. [GitHub](https://github.com/sapientinc/PRAXIST)
- **Cursor Projects** — New Cursor primitive: a coordinator agent that keeps shared context across sessions, delegates to parallel subagents, and can watch Slack/PRs/schedules to run recurring work without a fresh prompt.
  *Traction:* Shipped Sept 10 inside Cursor; paired with the Sept 3 rollout of cloud agents on customer-managed infra (AWS Lambda, Cloudflare, Modal, E2B, Vercel).
  *Why it matters:* Moves Cursor from per-chat assistance to persistent agent orchestration — pressures Devin, Claude Code and Codex on long-running workflows. [Cursor](https://cursor.com)
- **CopilotKit OpenBot** — Open-source AI "coworkers" with isolated browser + files + tools per agent, gated pre-execution, AG-UI compatible; WebMCP integration lets ChatGPT Atlas, Comet and Dia browsers invoke any tool registered via `useFrontendTool`.
  *Traction:* 4.8k GitHub stars (up from the 3.5k CopilotKit blogged this month).
  *Why it matters:* Standard-track integration turns any OpenBot tool into a callable action for the new agentic browsers. [GitHub](https://github.com/CopilotKit/OpenBot)
- **m3e-canvas** — Browser tool for sketching Material 3 Expressive screens and exporting them as vibe-coding prompts (Next.js/React/TypeScript).
  *Traction:* 6.5k GitHub stars since Sept 2 launch — fastest-climbing design-to-prompt project this week.
  *Why it matters:* A working example of the "design-in, prompt-out" hand-off replacing static mockups in agent-coding workflows. [GitHub](https://github.com/lnkiai/m3e-canvas)
