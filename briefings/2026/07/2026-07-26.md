## 🛠️ New tools gaining traction

- **Agency-Agents** — Framework that treats AI agents as specialized "employees" with personality profiles and named deliverables.
  *Traction:* +2,114 GitHub stars in the last week, the fastest-growing agent framework on GitHub trending. [Trend report](https://www.analyticsvidhya.com/blog/2026/07/trending-ai-github-repositories/)
  *Why it matters:* First agent framework built around HR-style role definitions rather than tool schemas — collapses onboarding time for non-ML operators.

- **OfficeCLI** — Free open-source Office suite for AI agents to read and edit Word, Excel, PowerPoint.
  *Traction:* Featured on this week's OSSInsight top-AI-repos board, and getting picked up by teams wiring MCP into Microsoft 365 workflows. [OSSInsight](https://ossinsight.io/trending/ai)
  *Why it matters:* Removes the biggest friction in enterprise agent pilots — turning a Claude/GPT output into a native `.docx` or `.xlsx` without a paid API.

- **OmniRoute** — Multi-provider AI gateway routing across 231+ providers.
  *Traction:* Same trend list, direct competitor to OpenRouter ($1.3B valuation) — enterprise buyers evaluating both this quarter. [OSSInsight](https://ossinsight.io/trending/ai)
  *Why it matters:* The router layer is where enterprise procurement is standardizing; open alternatives are becoming procurement-defensible.
